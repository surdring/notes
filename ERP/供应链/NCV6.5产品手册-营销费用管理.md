## 第一章 概述

### 1.1 产品概述

营销费用管理支持客户费用、助促销品两大类型营销费用的过程管控。

1) 客户费用:主要是需要兑付给客户的费用。包括返利金、各种补贴和客户代垫等费用。常见的兑付方式,包括:生成红字应收、订单冲抵、发票冲抵、赠品兑付、生成收款单。客户费用单可以来自费用申请,受费用申请控制;也可以自制。返利的客户费用单,可基于销售返利产品的返利结算单生成。

> 红字应收:客户费用单生成红字应收单,用于客户应收账款冲抵(蓝字应收单与红字应收单对冲),或者现金支付(红字应收单与付款单核销)。这种模式常见于个别费用支出,或对即将终止交易的经销商进行费用兑付,或基于KA 客户的垫款兑付,其特点是,不影响销售过程,以费用形式记账,做不到退税。

> 订单冲抵:指客户费用用于销售订单冲抵,销售订单将客户费用做折价处理。是常见的客户费用兑付方式。销售订单的最终金额,成为扣除客户费用后的金额。在实现客户费用兑付的同时,做到了合理退税。适用于订单定价,发票不改价的使用。

> 发票冲抵:指客户费用用于销售发票冲抵,销售发票将客户费用做折价处理。是常见的客户费用兑付方式。销售发票的最终金额,成为扣除客户费用后的金额。在实现客户费用兑付的同时,做到了合理退税。适用于订单价格不作为最终价格,发票可能修改价格的情况。

> 赠品兑付:指客户费用以货物形式补给客户,赠品兑付的商品有一定的范围,不允许随意兑付商品。赠品订单是独立的订单,不需要开具发票,不传应收,独立的赠品订单,根据“赠品现销销售”的原则,需要退税。

> 生成收款单:客户费用单生成收款单,面向分销商,对共的返利及费用支持一般转为预收款,可以与订单或应收款核销,另外,经销商年底法定以后不再合作,其原有货池中的金额,可以转为预收,与其应收账款,或后续退款给该经销商。

2) 助促销品:营销中宜促销品的发放也会带来营销费用。助促销品出库只能基于助促销品申请生成,受助促销品申请控制。

营销费用支持预算控制:

1) 客户费用申请可做预算预占,受预算控制。
2) 助促销品申请可做预算预占,受预算控制。
3) 客户费用单,可做预算占用,受预算控制。

#### 图11-1 营销费用管理解决方案

营销费用管理的总体解决方案。除了解决基本的费用管控、费用申请、费用兑付问题之外,还解决费用归集、收入还原、获利分析、费比分析。

1. **营销费用归集:**从各种来源归集获得营销费用数据。包括将以各种方式兑付的客户费用,随单销售的价格折扣、赠品,报销费用以及用于营销活动的助促销品等。原则是:全面归集,受益者承担费用。
2. **费用分析:**基于归集到的费用,分析各维度、各核算要素费用金额。
3. **收入数据获取:**基于合理性原则,以价格折扣前、费用冲抵前、赠品价格分摊前金额作为收入金额,即收入还原,以销售出库数据作为收入数据来源。
4. **费比分析:**以费用数据/收入数据,分析费比。可以分多种维度,分析各核算要素的分项费用比。
5. **成本获取:**基于存货核算实际成本数据获取。
6. **获利分析:**以收入-成本-费用,分析获利。其中收入、成本、费用的说明如前文所述。从而做到收入还原、费用由受益者承担,可以分多种维度,如:利润中心、成本中心、客户、产品品类等。

▶ 冲抵销售订单金额(票扣法)

* 在【销售订单】可以通过“费用冲抵”按钮或“现金处理”按钮处理货款冲抵，即票扣法；
* 票扣法，在【客户费用单】交易类型“支付方式”为“冲抵销售金额”设置，【客户费用单】可以支持对【销售订单】进行费用冲抵；
* 费用冲抵规则是按照“客户产品线+订单类型+销售组织+结算财务组织”维度进行冲抵，系统是通过【客户费用单】交易类型设置实现的；
  + 客户：根据【客户费用单】交易类型属性取《订单》客户或者开票客户；
  + 产品线：【客户费用单】的产品类型非空时，按照产品线进行费用冲抵；产品线为空时，可以与任意产品线的物料进行费用冲抵。当【销售订单】行物料对应的产品线为空时，可以和任意产品线的【客户费用单】作费用冲抵；
  + 订单类型：【客户费用单】的订单类型为空时，可以与任意订单类型的订单进行费用冲抵；订单类型非空时，严格按照订单类型进行费用冲抵；
  + 销售组织：根据【客户费用单】交易类型属性确定是否严格匹配；
  + 结算财务组织：【销售订单】表体行的结算财务组织必须严格与【客户费用单】的财务组织相同，若同一订单存在多个结算财务组织时，可以查看到多个财务组织的费用单；
* 在【销售订单】录入的费用冲抵金额按照【客户费用单】单据日期先后顺序，根据费用冲抵规则进行冲抵；
* 系统支持按照冲抵比例处理、控制订单费用冲抵，通过参数“S015销售发票/订单费用冲抵金额比例”控制，即【销售订单】冲抵金额不能大于：销售订单表头冲前金额\*参数比例。

▶ 冲抵销售发票金额(票扣法)

* 【销售发票】的费用冲抵业务应用与【销售订单】比较类似，区别是【销售发票】费用冲抵支持自动冲抵，通过参数“S014发票与客户费用单自动作费用冲抵”决定；

▶ 生成红字应收(账扣法)

* 通过【客户费用单】交易类型“支付方式”为“生成红字应收”设置，即账扣法：在【客户费用单】“生成红字应收”按钮处理自动生成红字【应收单】，进入【应收单】维护界面，编辑生成红字应收金额，默认等于“冲抵金额”，禁止客户费用单生成红字应收金额，超出客户费用单金额；
* 【客户费用单】生成红字【应收单】，按照单据接口关系定义确定生成红字【应收单】交易类型，同一【客户费用单】可以生成多张红字【应收单】；
* 【客户费用单】按照“订单客户”冲减应收，与“开票客户”无关；
* 【客户费用单】按照“开票客户”作费用冲抵时，如果【销售发票】未审核之前，始终按照【客户费用单】上的“订单客户”冲减信用占用。【客户费用单】对应销售信用占用(释放)影响，具体应用请参见“销售信用”手册的销售信用模型描述说明；
* 【客户费用单】可以通过【客户费用单】交易类型设置“审核自动生成凭证”勾选，直接自动生成总账财务凭证，实现计提摊销费用和待摊费用处理；

* ■ 营销费用归集是从内部管理角度进行费用统计，以利润中心为主体，并按照营销费用对应核算要素进行分析。
* ■ 营销费用按照“受益者”进行归集，统计维度根据营销费用归集单交易类型确定，包括：成本中心、项目、客户、产品线、品牌、物料。
* ■ 营销费用归集条件：利润中心、会计期间、归集单类型
  + ✓ 利润中心：营销费用归集的主体，所有来源单据必须明确所属利润中心才能参与归集计算；
  + ✓ 会计期间：利润中心对应会计期间方案的会计月份，用于确定来源于归集单据的统计日期范围；
  + ✓ 归集单类型：营销费用归集单交易类型，确定费用归集维度，用于匹配营销费用归集设置，以确定来源于归集范围。
* ■ 支持返利费用归集：基于已审批通过的返利结算单进行费用归集
  + ✓ 支持根据返利期间结束日期、单据日期或者审批日期对应会计期间进行归集，根据【营销费用归集设置】确定。
  + ✓ 若营销费用归集单交易类型设定的归集维度在返利结算单中为空值，则基于【营销费用分摊规则】将返利结算数据按费用归集维度充分摊再归集。
* ■ 支持客户费用归集：基于已审批通过的客户费用单进行费用归集
  + ✓ 支持根据单据日期或者审批日期对应会计期间进行归集，根据【营销费用归集设置】确定。
  + ✓ 由于返利费用基于返利结算单进行费用归集，因此来源于返利的客户费用单不参与客户费用归集。
* ■ 支持报销费用归集
  + ✓ 当费用报销单勾选分摊标记时，按照报销单结转后的结果进行费用归集；
  + ✓ 当费用报销单未勾选分摊标记时，按照已审批通过的费用报销单进行费用归集。
* ■ 支持促销品费用归集：基于已出库的促销品对应费用金额进行归集，费用受益维度根据助促销品申请单对应的费用申请明细信息获取。

## 2. 物料

物料档案由多个页签构成，这些页签又分为基本信息页签和组织信息页签两类，其中基本信息页签只有一个，用来设置物料公共属性，这些属性不随物料所在的组织不同而不同。

物料的组织页签包括销售、销售、库存、计划、生产和成本多个，用来设置物料在不同的组织类型下的属性，比如在销售组织信息页签中，记录的就是该物料在不同的销售组织的销售信息，由于一种物料可以在多个销售组织进行销售，也可以被存储在多个组织中，因此一个物料只能有一个物料基本信息，但该基本信息可以对应多个组织类型下的多个组织信息。

基本信息页签包括物料分类、主计量单位、是否服务、是否价格折扣、实物物料管理模式、是否成套件、税目、产品生命周期、单位体积、单位重量、是否零件、多少标准存储单位、入库容差、出库容差、出库关团下容差、电子采购等；入库容差(%)：定义由上游单据生成下游入库单据时，允许入库的差额；出库容差(%)：定义由上游单据生成下游出库单据时，允许出库的差额；出库关团下容差(%)：定义由上游单据生成下游出库单据时，上游单据自动进行出库关闭的条件。
