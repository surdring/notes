# 名词解释

**担保物权：**指债务人（或担保人）或者第三人，向债权人提供作为债权担保的财产，包括不动产、动产、权利等。

**担保合同：**指为促使债务人（或担保人）履行其债务，保障债权人的债权得以实现，而在债权人（同时也是担保权人）和担保人之间，或在债权人、担保人和第三人（即担保人）之间协商形成的，当反担保人不履行或无法履行债务时，以一定方式保证债权人债权得以实现的协议。担保合同旨在明确担保权人和担保人之间的权利、义务关系，保障债权人的债权得以实现。本文所指担保合同是当前组织为担保人的担保合同。

## 2.2 担保物权

### 2.2.1 业务描述

担保物权管理，指对债务人或第三人为保证担保合同履行，而向债权人提供的财产和权力的管理。当债务人或第三人采用抵押、质押担保形式时，先将抵质押物登记到系统中，以便担保合同使用。

1. 担保物权管理可以单独使用，也可与商业汇票集成应用。
2. 直接进行抵押、质押物权登记（如果不使用抵押或质押担保方式，可不行此步骤的处理）；
3. 也可由商业汇票的应收账款质押，形成抵押物权。
4. 抵质押物权确认后，形成待押物权，可在登记担保合同时引用。

## 2.2.4 产品解决方案

### 担保物权管理业务处理

1. 如果担保物权来自“商业汇票”或与“商业汇票”没有集成应用，则直接登记抵质押协议中的担保物权。
2. 担保物权的使用范围可为本单位，也可为全局共享，以支持客户的担保物多公司共用的应用场景。
3. 在【担保物权管理】功能节点中，录入抵质押物权信息。如果担保方式为“抵押、质押、混合”时，才需要登记担保物权，如果担保方式为“保证”，则不使用担保物权。
4. 【担保物权】保存后，必须进行确认，物权状态为“待押物权”，才可被担保合同直接引用。
5. 【担保物权】被合同引用后，物权状态即为“已押物权”。
6. 【担保物权】被合同引用后，可以变更“数量、单位、单价、质量、状况、所在地、当前评估价值等信息”。
7. 合同结束时，系统自动释放其引用的“担保物权”，物权状态为“已解物权”。注意：如果担保合同为多笔票据担保，则最后一笔授信结束时，才可将合同结束。
8. 已解除抵质押的物权，可再次被担保合同引用。已解除抵质押的物权，也可被“停用”，状态为“已停物权”，可重新启用。在没有启用时，将不会被担保合同引用。

### 商业汇票产生担保物权业务处理

1. 如果担保管理与“商业汇票”集成应用，则担保物权可来自“商业汇票”的“票据质押”。
2. 在商业汇票模块中，通过【票据质押】功能，录入票据质押的信息，审批后自动生成担保管理的质押物权。
3. 【担保物权管理】功能中，不可删改商业汇票生成的质押物权，也不可停用和变更生成的质押物权。
4. 商业汇票生成的【担保物权管理】中的质押物权状态为“待押物权”。
5. 合同结束时，系统自动释放其引用的“担保物权”，物权状态为“已解物权”。
6. 已解除抵质押的物权，状态为“已解物权”，可再次被担保合同引用，也可被【票据质押】“收回”。已被【票据质押】“收回”的质押物权，状态为“已停物权”，将不会再被担保合同引用。

## 2.3 担保银行授信

担保银行授信业务：指担保管理与银行授信管理集成应用时，企业的担保合同可支持银行授信办理过程中，向银行提供担保的业务处理。

### 2.3.1 业务描述

1. 担保管理与银行授信管理集成应用。
2. 先将抵押、质押物权进行物权登记（如果不使用抵押或质押担保方式，可不进行此步骤的处理）；
3. 然后将担保合同进行登记、审批；
4. 登记授信协议时，直接引用担保合同。
5. 授信协议保存时，自动生成担保的占用类债务单据，且自动审批后占用担保额度。
6. 授信协议删除时，自动删除生成担保的占用类债务单据，且自动删除占用担保额度。
7. 授信协议结束时，自动生成担保的释放类债务单据，且自动审批后释放占用的担保额度。
8. 担保合同结束时，释放担保物权。

### 担保管理业务处理

1. 如果银行授信的担保方式为“信用”时，不需要进行担保业务处理。如果银行授信的担保方式为“抵押、质押、保证、混合”方式时，先在系统中进行担保业务处理。
2. 如果银行授信的担保方式为“保证”时，不需要进行担保物权的处理。如果担保方式为“抵押、质押、混合”方式时，应先在【担保物权管理】功能节点中，录入抵押、质押物权信息，然后进行确认。

4. 【担保合同】保存并通过审批后，在银行授信协议中就可直接引用。
5. 【担保合同】由银行授信引用并保存后，系统自动“执行”。银行授信结束时，关联担保合同自动“结束”。

2. 如果债务的担保方式为“保证”时，不需要进行担保物权的处理。如果担保方式为“抵押、质押、混合”方式时，应先在【担保物权管理】功能节点中，录入抵押、质押物权信息，然后进行确认。

3. 将【担保合同】保存并通过审批处理，债务办理后，在【担保债务单据】中，新增“占用”类单据，录入债务关联的担保合同号和保函占用担保额度。

4. 【担保债务单据】保存后，系统自动登记【担保合同】占用担保金额，合同自动“执行”。

5. 债务到期后，在【担保债务单据】中，新增“释放”类单据，录入债务关联的担保合同号和债务释放占用担保额度。

6. 【担保债务单据】保存后，系统自动登记【担保合同】释放占用担保金额，合同自动“结束”。注意：如果担保合同为多笔债务担保，则最后一笔债务结束时，才会将合同结束。

7. 合同结束时，系统自动释放其引用的“担保物权”。
