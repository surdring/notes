## 2 系统平台功能

### 2.1 预警平台

通过预警平台统一管理按一定条件触发的业务预警。业务预警功能就是通过当前系统运行的指标、数据与各类预设该条件预算的比较,当达到条件后自动向相关人员来发出警告性的提示信息,用于提示企业的管理者针对将来或已经发生的情况采取相应的措施,及时进行处理。

#### 2.1.1 预警消息查询

##### 2.1.1.1 概述

预警消息查询是管理性质的功能,方便用户查询当前产生的所有预警消息以及预警平台已经发送出去的历史预警消息,可以查询到当前登录组织下所有的预警信息。而消息中心和邮件、短信,都是只有当前用户是消息接收人,才能看到消息。

预警消息查询包括如下两类消息:

* 本月最新消息:显示最近一个月产生的预警消息。
* 历史消息:可以查看一个月以前已经发送的预警消息。

* **删除：**可以删除预警消息。

## 2.1.2 业务预警监控

### 2.1.2.1 概述

业务预警监控是对预警平台配置的所有预警条目进行监督控制，一个任务分为等待运行、正在运行、运行完毕等几个状态，业务预警监控中心可以临时启动一个等待调度的任务。

#### 主要功能

* **执行：**对于任务列表中的任务，如果处于等待状态，可点击【执行】按钮，开始执行任务。任务被执行后本条任务的运行次数+1。上次耗时记录上次执行该任务使用的时间。
* **挂起：**把执行中的预警任务暂停执行。

### 2.2.1 后台任务监控

#### 2.2.1.1 概述

后台任务监控是对后台任务部署的所有任务条目进行监督控制，但是不包含临时任务。
一个任务分为等待运行、正在运行、运行完毕等几个状态。后台任务监控中可以临时启动一个等待调度的任务。

#### 2.2.1.2 产品功能

* **界面**![后台任务监控界面截图，显示了任务名称、任务标识、类型、执行、删除、暂停、启动等操作按钮，以及任务状态、部署公司、计划时间（调度服务器时间）、上次耗时等信息。]()
* **主要字段：**
  + 任务名称、任务标识、类型：指本条监控任务定义的基本信息。

  + 状态：任务的执行状态，分为等待、可执行、运行中、完成、暂停、失败、取消中、已取消。
  + 计划时间：按照任务部署、任务实体下次计划运行的时间。
  + 上次耗时：对于多次执行的任务实体，记录上次运行消耗的时间。
  + 运行次数：记录任务实体已经运行的次数。
* **注意事项：**
  + 显示系统中所有已经进入调度引擎的任务。
  + 对于任务列表中的任务，如果处于等待状态，可点击执行按钮，开始执行任务。任务被执行后本条任务的运行次数+1。上次耗时记录上次执行该任务使用的时间。
  + 对于处于等待和可执行状态的任务可以删除该任务实体。
  + 被删除以后，对应的预警条目不会再被执行，这种情况下，虽然在预警条目配置界面还能看到该条目，但实际上它已经不发挥作用了，除非重启后中间件或者修改该预警条目。

## 2.7.7 物化视图

### 2.7.7.1 概述

显示数据处理平台的可执行数据源下的所有物化视图信息，可进行刷新等操作。

物化视图，它是用于预先计算并保存表连接或聚集等耗时较多的操作的结果，这样，在执行查询时，就可以避免进行这些耗时的操作，从而快速的得到结果。物化视图有很多方面和索引很相似：

1. 使用物化视图的目的是为了提高查询性能；
2. 物化视图对应用透明，增加和删除物化视图不会影响应用程序中 SQL 语句的正确性和有效性；
3. 物化视图需要占用存储空间；
4. 当基表发生变化时，物化视图也应当刷新。
