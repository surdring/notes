**信用证 LC (Letter Of Credit)**

是指开证银行应申请人之要求并按其指示，向第三者开具的载有一定金额、在一定期限内凭符合规定的单据付款的书面保证文件。信用证按付款时间分为：即期信用证、远期信用证。

**电汇 T/T (Telegraphic Transfer)**

是指汇出行应汇款人申请，拍发电押汇报单、电传或 SWIFT 给在另一国家的分行或代理行（即汇入行）指示解付一定金额给收款人的一种汇款方式。T/T 付款方式是以外汇现金方式结算，由客户将款项汇至出口方指定的外汇银行账号内，可以要求货到后一定期限内汇款。T/T 分预付，即期和远期。

**付款交单 D/P (Documents Against Payment)**

是出口人的交单以进口人的付款为条件，即出口人将汇票连同货运单据交给银行托收时，指示银行只有在进口人付清货款时才能交出货运单据。按支付时间分为：即期付款交单 (D/P at sight)、远期付款交单 (D/P after sight)。

**承兑交单 D/A (Documents Against Acceptance)**

指出口人的交单以进口人的承兑为条件。进口人承兑汇票后，即可向银行取得货运单据，待汇票到期日才付款。承兑交单只适用于远期汇票的托收，有风险，主要看客户的信用。

**赊账交易 O/A (Open Account Trade)**

即货到付款，风险大。

**付现交单 CAD (Cash Against Documents)**

由于货款之交付在出口地，出口商在出口地未收货款即不交付提单，风险较小。

**信用保险**

是指权利人向保险人投保债务人的信用风险的一种保险，是一项企业用于风险管理的保险产品。其主要功能是保障企业应收账款的安全。其原理是把债务人的保证责任转移给保险人，当债务人不能履行其义务时，由保险人承担赔偿责任。主要包括两种：商业信用保险、各国政府为提高本国产品出口竞争力而提供的信用保险。

**结汇单证**

是指在国际贸易结算中，为解决货币付问题所使用的各种单据及证明。结汇单证是进出口贸易中必不可少的重要单证。出口货物装运之后，出口方按合同或信用证要求，正确编制各种单证（如箱单、发

## Page 6

票、提单、保险单、产地证明等），并在信用证规定的有效时间内，送交银行议付和结汇，从而完成一笔有效的出口任务。

**箱单** *Commercial Invoice*

是发票的补充单据，它列明了信用证（或合同）中买卖双方约定的有关包装事宜的细节，便于国外买方在货物到达的港时供海关检查和核对货物，通常可以将其有关内容加列在商业发票上，但是在信用证有明确要求时，就必须严格按信用证约定制作。

**商业发票** *Commercial Invoice*

是卖方向买方开立的，凭以向买方收取货款的发货价目清单，是装运货物的总说明。作用如下：

* 卖方向买方的发货凭证，是卖方重要的履约证明文件；
* 便于进口方核对已装运的货物是否符合买卖合同的规定；
* 是进出口双方凭以收付货款和记账的重要凭证；
* 是进出口双方办理报关、纳税的重要依据；
* 索赔和理赔的重要凭证；

**海关发票**

根据某些进口国海关的规定，由出口商填制的一种特定格式的发票，它的作用是供进口商凭以向海关办理进口报关、纳税等手续。该发票由出口方逐项填写，进口方据此办理货物的报关进口手续。它是某些国家执行差别待遇政策和排挤别国商品进口的一种工具。海关发票内容与商业发票基本相同。

**托单** *Shipping Note*

是发货人发货给货运代理人的订舱委托单据，相当于协议或者说合同。托单制作依据是出口货物信息以及收货人提供的收货人信息，包括抬头、地址、传真、电话等。

**出运联系单**

联系单是各个部门进行备货、出运、制单结汇的共同依据。

**出口专用发票**

由国家税务机关监制，一式七联，存根联、发票联购货方记账凭证、出口单位记账联、税务机关存根联、海关查存联、外汇管理局存查联，第七联空白，必须一式七联按顺序电脑打印，不得手写。

**贸易方式**

是指国际贸易中买卖双方所采用的各种交易的具体做法，如：一般贸易、来料加工、进料加工、补偿贸易、租赁贸易等。

**贸易术语** *Trade Terms*

也被称为价格条款 (Price Terms)，是国际贸易中习惯采用的、用简明的语言来概括说明买卖双方在货物交接方面的权利与义务，其主要内容是规定买卖双方在货物交接方面的责任、风险和费用的划分。

## 1.1 产品概述

NC进出口产品，是基于 NC-UAP 平台，包括进出口基础设置、自营进口、自营出口、代理进口、代理出口、转口贸易、贸易费用模块，紧密贴合企业的实际业务，与采购、销售、库存、财务、生产等产品一起，构成进出口企业的完整解决方案。进出口产品与内贸产品帮助企业整合内外贸信息，打造企业供应链。

进出口产品在 V631 版本推首出发版，和供应链、财务、资金等模块一起，为进出口企业提供了完整的解决方案，产品填补了内贸所不能满足的进出口的特色业务，比如：单证管理、储运工作台、代理进口、代理出口等，并与资金产品紧密集成，实现了业务、财务、资金一体化。

## 1.2 产品价值

1. **支持直接转口、保税转口两种业务模式**
   * 直接转口
     + 将货物直接从出口国运往进口国。
     + 第三国（转口国）只处理相关贸易单据，没有物流。
   * 保税转口
     + 货物到港后先入第三国（转口国）的保税仓库，有时会进行混装、分级等处理，后从保税仓库出库运往进口国。
     + 转口国既处理相关贸易单据，又管理物流。
2. **支持内外贸一体化应用**
   * 储运工作台
     + 支持搭配采购入库单、调拨入库单、其它入库单。
3. **支持转口特色业务**
   * 单证管理
     + 支持结汇单证。
   * 储运工作台
     + 支持搭配入库单、搭配关闭、搭配打开等。
   * 对转口贸易过程中发生的费用进行管理，可明确到单，使得核算更为准确。
   * 转口引入调整发票，解决价格、金额调整问题，并影响收付，符合国际贸易处理方式。
4. **支持业务、财务、资金一体化应用**
   * 支持信用证管理
     + 转口合同收证、结汇单证交单环节业务发起，后续资金、财务处理，做到了业务决策，资金财务人员监管。
   * 支持收汇水单收款
     + 通过收汇水单向客户收取货款，生成收款单。
   * 支持发票管理
     + 支持转口发票、调整发票生成应收单。

## 2.1.2 业务流程

➤ 进口合同 → 进口明细单；

➤ 转口合同（搭配进口明细单） → 转口明细单（直接补单） → 采购入库单、销售出库单；

➤ 转口明细单 → 结汇单证；

➤ 销售出库单（签字） → 销售成本结转单；

➤ 转口明细单 → 转口发票 → 应收单；

➤ 收汇水单 → 认领到转口明细单 → 收款单。

## 3.1 管控模式

管控模式用于初始化时进行档案规则的配置,即针对每个档案根据最常规的应用方案,设置它的默认规则。用户可以在每个档案可支持的规则范围内进行调整,调整档案的规则时,需要同时受档案间的约束规则显示;

管控模式属全局级节点,拥有权限的用户(系统管理员)可以维护并查看全局内的全部数据,这些数据在数据库内唯一;

一个档案只能在可选择的管控模式范围内选择,按照“管控模式”配置的不同,档案将分为全局级、集团级、组织级的多个节点,通过集团管理员完成功能授权后交由指定操作员使用;

管控模式设置包括:管理模式配置、可见性范围和唯一性范围;管控模式配置是定义节点可维护数据的最大范围;可见性范围是决定用户可以查看、使用基础数据的最大范围;唯一性范围是决定基础数据唯一性的范围;

## Page 32

系统对企业建模平台中大部分基础档案支持管控模式，进出口管理中的收款起效时点、付款起效时点支持管控模式；

当档案存在存储时，管控模式只能细化调整，即切换后的管控模式要包含当前管控模式决定的所有节点，且调整后管控模式的唯一性校验范围只能小于等于原管控模式的唯一性校验范围；

管控模式影响到后续业务方案的实现，是业务建模中的重要环节，务必将所有业务分析清楚，多角度判断有无遗漏后再设定；关于管控模式的具体应用设置请参见《产品手册-系统管理》内容。

## 3.2 企业建模平台

### 3.2.1 多组织建模

通过设置财资组织、库存组织、销售组织、采购组织、物流组织等相关业务组织，支持多组织架构，同时还可通过交叉、多级、跨组织的业务委托关系，实现集团出口业务的多组织业务协同。

组织建立系统中包括业务单元、销售业务委托关系、物流业务委托关系等，具体操作应用请参见《产品手册-组织管理》。

#### 3.2.1.1 组织管理

1. 组织结构定义-业务单元

对企业中的业务职能进行了划分，是企业中特定业务职能（业务及政策）的载体，是为了完成特定业务职能而划分的具有相应功能权限的单位。比如：财务业务单元完成财务核算的功能；销售业务单元完成销售业务的功能；物流业务单元完成储运发货的功能等；

2. 业务委托关系定义-销售业务委托关系

销售业务必须设置销售业务委托关系。按照“销售组织+产品线”设置发货库存组织、结算财务组织、应收组织、利润中心等。同一个“销售组织+产品线”可以设置多个发货库存组织，默认发货库存组织唯一。

2. 业务委托关系定义-物流业务委托关系

定义库存组织与物流组织的业务委托关系，一个库存组织可委托多个物流组织做收发货的安排，默认的收发货组织在组织唯一且最优，一个物流组织可负责多个库存组织的收发货安排。

针对不同业务类型支持灵活自定义业务流,业务流定义基于“交易类型”配置相应的业务单据流程、销售结算规则等,实现多种销售业务类型处理的需要。强调以流程为导向完成日常的业务管理操作;

### 1. 交易类型管理

交易类型是一个业务的上下游环节进行衔接时所遵循的约束规则。当上下游单据之间采用不同的交易类型流转,即采用不同的约束规则进行业务处理会得到不同的业务结果;通过交易类型的设置,可以让同

**转口合同类型:**

* 自动询价
  + ✓ 是: 根据销售组织参数[ET05 销售询价触发条件]的设置来自动触发销售询价;
  + ✓ 否: 不自动询销售价格;
* 询到价格是否可改
  + 若【自动询价】为“是”,则默认值为“是”,可编辑;否则,为“否”,不可编辑。
    - ✓ 是: 询到的价格可修改;
    - ✓ 否: 询到的价格不可修改;主要适用于严格按照已制定的销售价格进行销售的业务;
* 修订询价
  + 若【自动询价】为“是”,则默认值为“是”,可编辑;否则,为“否”,不可编辑。
    - ✓ 是: 修订转口合同时,自动询销售价格;
    - ✓ 否: 修订转口合同时,不自动询价,即销售价格保持不变;
* 明细单出库数量修正合同执行数量
  + ✓ 是: 转口明细单出库关闭/打开时,修正转口合同的累计明细单主数量、修正量=明细单(累计出库主数量-主数量);
  + ✓ 否: 转口明细单出库关闭/打开时,不影响转口合同的累计明细单主数量;
* 合同变更过程中可生成转口明细单
  + 用于设置转口合同变更后、未审批通过前,是否可参照修订前的转口合同生成新的转口明细单。
* 合同变更过程中可收款
  + 用于设置转口合同变更后、未审批通过前,收汇水单是否支持认领修订前的转口合同。
