## 9. 备注：GPU[x] 与 /sys/class/drm/cardX 的映射

当前文档仅确认：
- `rocm-smi` 报告的 PCI Bus 分别为 `0000:05:00.0` / `0000:08:00.0`
- `/sys/class/drm/card0` / `card1` 的 vendor 均为 `0x1002`

若要将 `GPU[0]/GPU[1]` 精确映射到 `card0/card1`，可运行：

```bash
readlink -f /sys/class/drm/card0/device
readlink -f /sys/class/drm/card1/device
```

输出路径中会包含 `0000:05:00.0` 或 `0000:08:00.0`，据此即可一一对应。

### 9.1 已确认的映射结果（本机）

根据 `readlink -f` 的输出：

```text
/sys/class/drm/card0/device -> .../0000:08:00.0
/sys/class/drm/card1/device -> .../0000:05:00.0
```

并结合 `rocm-smi` 的 PCI Bus：

- **GPU[0]** PCI Bus = `0000:05:00.0`
- **GPU[1]** PCI Bus = `0000:08:00.0`

得到映射关系：

- **GPU[0] ⇔ /sys/class/drm/card1 ⇔ 0000:05:00.0**
- **GPU[1] ⇔ /sys/class/drm/card0 ⇔ 0000:08:00.0**

补充校验点（来自 sysfs）：
- `card1`: `device=0x66a1`, `subsystem_device=0x081e`, `revision=0x06`
- `card0`: `device=0x66a1`, `subsystem_device=0x0834`, `revision=0x01`

### 9.2 按卡设置锁频/锁 MCLK 的注意事项

如果你通过 sysfs 写入：
- `/sys/class/drm/card0/device/pp_dpm_*`，实际作用于 **rocm-smi 的 GPU[1]**
- `/sys/class/drm/card1/device/pp_dpm_*`，实际作用于 **rocm-smi 的 GPU[0]**

建议在双卡环境下，所有“设置类”操作都配合 PCI Bus 做映射确认，避免把参数写到另一张卡上。

### 9.3 如何在程序中选择使用哪张 GPU（HIP_VISIBLE_DEVICES）

对于 HIP/ROCm 程序（例如 `mi50_stress` / llama.cpp-hip），可以用环境变量选择 GPU：

- 使用 **GPU[0]**：

```bash
HIP_VISIBLE_DEVICES=0 <你的命令>
```

- 使用 **GPU[1]**：

```bash
HIP_VISIBLE_DEVICES=1 <你的命令>
```

示例（分别对两张卡跑 60 秒压力测试）：

```bash
HIP_VISIBLE_DEVICES=0 timeout 60s ./mi50_stress 60
HIP_VISIBLE_DEVICES=1 timeout 60s ./mi50_stress 60
```

### 9.4 systemd 启动 llama-server 的环境变量注意事项（env -i / 重编号 / 验证）

- **HIP_VISIBLE_DEVICES 会导致“进程内重编号”**：例如设置 `HIP_VISIBLE_DEVICES=1` 后，进程只看到一张卡，并可能将其编号为 `0`。因此 `rocm-smi --showpids` 里的 `GPU(s)` 字段在某些组合下可能显示为 `0`，不一定等同于全局的 `GPU[0]/GPU[1]`。建议以推理时 `rocm-smi --showmemuse/--showpower` 哪张全局 GPU 有变化为准。
- **systemd 的 Environment 与 ExecStart 可能“互相覆盖”**：若 `ExecStart` 采用 `/usr/bin/env -i ... HIP_VISIBLE_DEVICES=...` 显式传入变量，则会以 `ExecStart` 中的值为准，即使 unit 文件里还有 `Environment="HIP_VISIBLE_DEVICES=..."` 也可能被覆盖。要修改绑定 GPU，需要同时检查 unit 中 `Environment=` 与 `ExecStart` 里传入的变量是否一致。
- **推荐的验证方式**：
  - `systemctl --user show <unit> -p ExecStart -p Environment --no-pager`
  - `PID=$(systemctl --user show -p MainPID --value <unit>); tr '\0' '\n' < /proc/$PID/environ | grep HIP_VISIBLE_DEVICES`
